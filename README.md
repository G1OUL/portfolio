# Hariom Upadhyay — Portfolio

Premium static **Midnight Sakura × AI/Data** portfolio.

## Includes
- Animated Japanese cherry-blossom hero
- Falling sakura petals
- Glassmorphism UI
- Responsive design
- Data + AI focused profile
- Five project links
- No framework or build step

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Go to **Settings → Pages → Deploy from a branch → main → /(root)**.

Portfolio repository: https://github.com/G1OUL/portfolio
